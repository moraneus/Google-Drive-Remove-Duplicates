Drive Dedupe

Find and safely remove duplicate files in your Google Drive

1 · Connect

Checking connection…

To connect, the app needs its own free Google OAuth client ⓘ — a one-time setup:

  1. Create a Google Cloud project ⓘ
  2. Enable the Google Drive API ⓘ
  3. Set up the consent screen ⓘ
  4. Create an OAuth client and download its JSON ⓘ

⚠️ Keep this file private. It identifies the app to Google — don't share it, email it, or commit it to git. Uploading stores it only on this computer (~/.gdrive-dedupe/credentials.json), and you can delete it there any time.

Scanning uses a read-only scope — the app cannot modify anything.

4 · Clean

Files are moved to Drive's trash (recoverable for 30 days). An audit log is kept locally, and you can undo the last batch here.

5 · Empty folders

Folders with no files anywhere inside (folders that only contain other empty folders count too). Trashing a folder also removes its empty subfolders.

6 · Older files

Find files you haven't touched in years. These are unique files (not duplicates), so nothing is pre-selected — tick only what you're sure about.
