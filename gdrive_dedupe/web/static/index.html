Connect your Drive

Checking connection…

The app needs its own free Google OAuth client — a one-time setup:

  1. Create a Google Cloud project
  2. Enable the Google Drive API
  3. Set up the consent screen
  4. Create an OAuth client and download its JSON

Keep this file private. It identifies the app to Google. Don’t share it, email it, or commit it to git. Uploading stores it only on this computer, at ~/.gdrive-dedupe/credentials.json; delete it there any time.

No browser tab opened? Open Google’s consent page to approve access.

Scanning uses a read-only scope. The app can’t change anything until you start a cleanup and grant write access separately.

Scan your Drive

Reads file names, sizes and checksums. No file contents are downloaded.

Review duplicates

Two files are duplicates when Google’s checksums match, so their contents are identical byte for byte.

Clean up

Files go to Drive’s trash, where they stay recoverable for 30 days. Every batch is written to a local audit log first, and you can undo the last one here.

Past batches and freeing storage

Files in Drive’s trash still count toward your storage until the trash is emptied. “Delete permanently” empties the files of one batch, only those still in the trash, and can’t be undone.

Empty folders

Folders with no files anywhere inside, counting subfolders. Trashing a folder removes its empty subfolders too.

Old files

Files you haven’t touched in years. These are unique files, not duplicates, so nothing is pre-selected.

Largest files

Your biggest files first, the quickest way to free space when Drive is full. Nothing is pre-selected.
